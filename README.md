# Calculadora

Este é um projeto de uma **calculadora simples**, desenvolvida em **C#** com a interface gráfica utilizando **Windows Forms**. A aplicação permite realizar operações matemáticas básicas de maneira intuitiva e prática.

---

## Funcionalidades

- **Operações Básicas**:
  - Soma (`+`)
  - Subtração (`-`)
  - Multiplicação (`×`)
  - Divisão (`÷`)
- **Outras Funções**:
  - Apagar (`C`) para limpar o valor exibido.
  - Pontuação (`.`) para operações com números decimais.

---

## Estrutura do Projeto

- **Namespace:** `Calculadora`
- **Classes**:
  - `Form1`: Responsável pela interface gráfica e controle dos eventos.

### Componentes Principais
- `TextBox textoResultado`: Exibe o número ou resultado das operações.
- Botões de números (`0` a `9`) e operações (`+`, `-`, `×`, `÷`, `=`).
- Botão `C`: Limpa a tela.
- Botão `.`: Para incluir pontos decimais.

---

## Interface Gráfica

A interface é composta por:
- Uma área para exibição do número atual e resultados.
- Botões bem organizados e com estilo simplificado, dispostos de forma similar às calculadoras convencionais.
